# Дополнительные читательские словари

В публичной версии v1.6.1 доступны независимые companion-пакеты для чтения русской и переводной
литературы. Они не смешиваются с основным RU-Max-Clean: каждый слой имеет свои
файлы `.ifo/.idx/.dict` и может быть включён в KOReader отдельно.

Технические имена папок сохраняются неизменными для совместимости, а в списке
словарей KOReader используются понятные русские названия: «Латынь — расширенный
словарь», «Литературные сокращения», «Фразеологизмы и устойчивые выражения» и
аналогичные названия для остальных слоёв.

## Пакеты

* `latin_classical` — в KOReader «Латынь — классические выражения»: распространённые
  латинские выражения и термины с русским объяснением;
* `latin_wiktionary` — «Латынь — расширенный словарь»: русские толкования латинских
  лексем из Wiktionary;
* `literary_archaic` — «Архаика и церковнославянская лексика»;
* `literary_wiktionary` — «Расширенная историческая лексика»;
* `french_literary` — «Французская лексика в литературе»: слова, титулы и выражения
  из русской классической прозы;
* `literary_names` — «Литературные имена и названия»: персонажи, исторические лица
  и географические названия;
* `fantasy_terms` — «Фэнтезийные термины»;
* `literary_terms` — «Историко-культурные термины»;
* `literary_abbreviations` — «Литературные сокращения» (`г-н`, `стр`, `примеч`);
* `phraseology` — «Фразеологизмы и устойчивые выражения».

Входной формат — UTF-8 TSV:

```text
слово<TAB>русское определение<TAB>алиас1|алиас2
```

Стартовые записи являются небольшой авторской seed-выборкой для проверки
формата и качества. Перед расширением источники необходимо проверять на
совместимость лицензий. Для массовых пополнений предпочтительны Wiktionary,
Wikidata и источники public domain/CC-compatible.

## Сборка пакетов

Из каталога builder:

```text
py -3 -X utf8 build_reader_packs.py --pack-dir reader_packs
```

По умолчанию результат записывается в единый корень готовых словарей:
`RU-Dictionaries/RU-Reader-Packs/<pack>/`. Чтобы выбрать другой корень, можно
передать `--output-root <каталог>`; старый сценарий с явным
`--output-dir RU-Reader-Packs` также остаётся совместимым.

Каждый пакет проходит обычную StarDict-валидацию:

```text
py -3 -X utf8 validate_stardict.py RU-Dictionaries\RU-Reader-Packs\latin_classical\ru-max-clean
```

Французский слой намеренно не объединяется с латинским: короткие служебные
слова (`de`, `la`, `en`) могут иметь совпадающие ключи, но относятся к разным
языкам и должны подключаться читателем осознанно.

## Политика качества

* Основной словарь остаётся русскоязычным и не получает массовых латинских
  или энциклопедических записей.
* Иностранные и архаические слои должны иметь явный язык/домен в метаданных,
  короткое русское объяснение и проверяемый источник.
* Автоматические алиасы добавляются только после проверки коллизий; исходная
  форма всегда сохраняется.
* Для каждого расширенного слоя формируются отдельные `PACK_INFO.json` и
  отчёт покрытия.
