RU Max Clean — тестовая книга словарей

Файлы: EPUB для большинства современных читалок и FB2 для KOReader/FBReader.
Книга полностью оригинальная и содержит контрольные слова по всем текущим слоям.

Порядок проверки: подключите ядро, затем включайте companion-паки по одному и открывайте слова долгим нажатием.
Проверьте обычную и изменённую форму, регистр, букву ё, дефисы, диакритику, кавычки и многословные выражения.
Раздел «Контрольная полоса» содержит короткий итоговый список.

Книга входит в builder-релизы GitHub как единственное небольшое QA-исключение;
готовые словари и пользовательские книги в релизы не входят.
