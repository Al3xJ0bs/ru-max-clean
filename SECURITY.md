# Security policy

Если проблема содержит секреты, токены или персональные данные, не публикуйте
её в открытом issue. Свяжитесь с владельцем репозитория через приватный канал
GitHub. Для обычных ошибок сборки используйте issue с версией, платформой,
командой запуска и минимальным воспроизводимым примером.
